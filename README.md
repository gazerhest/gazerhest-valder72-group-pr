# PC Assembly
Вебплатформа для створення власних конфігурацій ПК, а також пошук, порівняння та купівлі комп'ютерних комплектуючих.

## Functionality
- **Каталог запчастин**: Перегляд списку деталей з можливістю пошуку за назвою, фільтрацією за характеристиками й виробником, а також сортуванням за ціною та популярністю (оцінкою користувачів).

- **Детальна сторінка запчастини**: Перегляд її технічних характеристик, відгуків, оцінок від покупців.

- **Порівняння**: Можливість обрати кілька деталей одного типу та порівняти їхні характеристики.

- **Конструктор / Збірка ПК**: Можливість поетапно обрати сумісні комплектуючі, зберегти збірку у своєму профілі та порівняти з іншиим збірками, або одразу оформити на неї замовлення.

- **Особистий кабінет**: Реєстрація, збережені збірки, історія замовлень та редагування особистих даних (нікнейм, ПІБ, номер теоефону, пошта, адреса проживання).

## Endpoints
### Parts
- /parts:
  + Опис: Отримання списку деталей з підтримкою пагінації, пошуку, фільтрації та сортування
  + Request method: GET
  + Query Parameters:
      1. page: сторінку яку треба підвантажити
      2. limit: к-сть об'єктів на одній сторінці (базово 12)
      3. search: пошук за назвою
      4. filters: філтри які застосовані
      5. sort: спосіб сортування (по ціні або по рейтингу від найбільшого/найменшого до від найменшого/найбільшого
  + Request body: пустий
  + Response Status: 200 OK, якщо деталь знайдено та 404 Not Found, якщо такої деталі немає
  + Response Body: JSON-об'єкт з даними про товари (перші 12)
    
### Compare parts
- /parts/compare:
  + Опис: Отримання списку обраних товарів одного типу для порівняння їхніх характеристик
  + Request method: GET
  + Query Parameters:
        ids: список ID товарів через кому (наприклад '1,4,12')
  + Request body: порожній
  + Response Status: 200 OK, 400 Bad Request (якщо передано товари з різних категорій)
  + Response Body: JSON-об'єкт товарів із їхніми характеристиками для порівняльної таблиці
    
### Builds
- /builds:
   + Опис: Збереження нової конфігурації ПК (створеної у конструкторі)
   + Request method: POST
   + Query Parameters: відсутні
   + Request body: JSON-об'єкт із назвою збірки та масивом ID комплектуючих (процесор, відеокарта тощо).
   + Response Status: 201 Created (якщо збережено), 400 Bad Request (помилка сумісності або некоректні дані)
   + Response Body: JSON-об'єкт створеної збірки з її ID та підсумковою вартістю

- /builds/{id}:
   + Опис: Отримання детальної інформації про збережену збірку
   + Request method: GET
   + Query Parameters: відсутні
   + Request body: порожній
   + Response Status: 200 OK, 404 Not Found
   + Response Body: JSON-об'єкт з переліком усіх деталей у збірці, загальною ціною та автором
  
### Cart
- /cart:
   + Опис: Отримання вмісту кошика поточного користувача
   + Request method: GET
   + Query Parameters: відсутні
   + Request body: порожній
   + Response Status: 200 OK, 401 Unauthorized (якщо не залогінений)
   + Response Body: JSON-об'єкт зі списком доданих деталей/збірок та загальною сумою

- /orders:
   + Опис: Оформлення замовлення (перетворення кошика або збірки у замовлення)
   + Request method: POST
   + Query Parameters: відсутні
   + Request body: JSON-об'єкт із джерелом замовлення (ID кошика або ID збірки)
   + Response Status: 201 Created
   + Response Body: JSON-об'єкт створеного замовлення (номер замовлення, дата, статус, підсумкова сума)
     
### User profile
- /users/me:
   + Опис: Отримання та оновлення даних профілю авторизованого користувача.
   + Request method: GET / PATCH
   + Query Parameters: відсутні
   + Request body: (для PATCH) JSON-об'єкт з новими даними (ПІБ, телефон, адреса)
   + Response Status: 200 OK, 401 Unauthorized
   + Response Body: JSON-об'єкт профілю користувача.
